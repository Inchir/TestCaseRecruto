Tестовое: 
1) Создать веб-сервис который генерирует случайный четырёхзначный код. Новый код по обновлению страницы. Требуется скинуть URL и показать код на питоне.

**Сценарий работы**
1. На главной странице
    1. Генерация кода → задание 1
       1. Обновите страницу
    2. Генерация кода с регистрацией → задание 2
       1. Зарегистрируйтесь
       2. Войдите
       3. Вас перебросит на страницу с кодом
       4. Обновите страницу
